# Universal Bridge icon

`app-icon.png` is the project artwork, generated with the built-in image generation tool on 2026-10-17. `app.ico` is a Windows format conversion of the same artwork, preserving alpha, with 16/20/24/32/40/48/64/128/256-pixel frames. Regenerate the ICO on Windows with `pwsh -File scripts/Build-Icon.ps1`. No generation service is used at build time or runtime.

Final generation prompt:

> Use case: logo-brand. Create one polished Windows application icon for Universal Bridge, a utility sharing keyboard, mouse and trackpad control between a Windows PC and an iPad. This is a project asset, not a mockup or icon sheet. Square, straight-on, centered, generous clean silhouette. A rich blue rounded-square tile matching the app's existing cobalt-blue interface (#3167DA), with a very simple bold white symbol of two neighboring screen panels joined by one flowing bridge/link stroke. Modern, restrained, premium desktop app aesthetic, subtle depth and soft controlled highlights, clear at 16 and 32 pixels, thick crisp shapes and no fiddly details. Tile occupies most of the square with a small safe margin; actual transparent background outside the rounded tile. No words, no letters, no numbers, no watermark, no Apple or Windows corporate logos, no stock clipart, no extra objects, no surrounding scene. Deliver a single high-resolution PNG app icon with alpha.
