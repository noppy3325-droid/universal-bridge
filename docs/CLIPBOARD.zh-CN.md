# 使用Safari共享剪贴板

[English](CLIPBOARD.en.md) · [日本語](CLIPBOARD.md) · 简体中文

v1.06支持同一Wi-Fi内Windows与iPad之间的双向纯文本共享，无需iPad专用应用或互联网服务。通过明确的按钮操作传输，不支持自动同步、图片或文件。文本的UTF-8大小上限为64 KiB。

## 首次连接

1. 将电脑和iPad连接到同一Wi-Fi。在Windows应用的“剪贴板共享”中选择Wi-Fi的IP地址，开始共享。
2. 如果Windows要求网络权限，仅允许可信的专用网络入站连接，无需关闭防火墙或设置路由器端口转发。
3. 在iPad Safari打开首次设置网址（`http://…:43182/`）。该HTTP页面仅提供公用证书及设置说明，无法读写剪贴板，也不会要求输入连接码。
4. **与Windows应用核对证书名称及SHA-256**，然后下载公用证书。在“设置→通用→VPN与设备管理”中安装，在“通用→关于本机→证书信任设置”中信任此证书。受管理的iPad可能需要管理员协助。[Apple说明](https://support.apple.com/zh-cn/102390)。
5. 在Safari打开共享网址（`https://…:43183/`）。如果仍有证书警告，请停止并检查证书、信任设置及网址。输入Windows中显示的六位连接码。

私钥使用Windows账户加密并保存在电脑中，只向iPad提供公用证书。安装证书表示信任此电脑提供连接，请核对名称与指纹。不再使用共享时，可在iPad设置中移除添加的证书。

## 传送文本

- **Windows→iPad：** 在Windows应用中复制文本。在Safari点击“从Windows获取”，再点“复制到iPad”，然后粘贴到备忘录等应用。
- **iPad→Windows：** 在iPad复制文本，使用正常粘贴菜单将其粘贴到Safari的输入框，点击“发送到Windows”，再到Windows应用中粘贴。发送空输入框会清空Windows剪贴板。

如果复制按钮不可用，请长按已获取的文本进行选择和复制。复制操作遵循Safari对用户操作的要求。[WebKit说明](https://webkit.org/blog/10855/async-clipboard-api/)。

## 管理连接

- 连接码五分钟内有效，仅可使用一次。五次失败后需在Windows生成新连接码，此操作也会撤销已有页面的授权。
- 每次启动默认关闭共享。停止、退出、Windows会话变化或睡眠时撤销连接，恢复时需新连接码。共享网址可以收藏。
- 文本通过HTTPS加密传输，不监视剪贴板、不自动同步、不保存内容历史，也不记录连接码、Cookie或内容。操作系统的剪贴板历史及用户复制内容仍受系统和浏览器自身行为影响。
- 若无法连接，请检查Wi-Fi、所选IP、Windows入站权限和访客／企业Wi-Fi的设备隔离设置。IP变化后，请停止共享、刷新地址列表后重新开始。只要此电脑的公用CA不变，就无需重新安装证书。
