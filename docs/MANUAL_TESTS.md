# iPad実機受け入れチェック

## 0.4.0の追加確認（iPad実機は未実施）

1. 旧版を完全終了し新版を起動。抑制オン／オフと同じ感度で、ゆっくりした浅い斜め移動・急なフリック・反転・ドラッグを比較する。止めた後の移動、クリック解除の欠落がないことを確認する。抑制オンでは速い移動距離が短くなることを確認する。
2. 互換モードで2本指の微小な縦／横スクロールと反転を試す。初動の待ち・停止後の振動、物理ホイールとの独立性を確認する。
3. 入力設定の接点モードをオンにし完全終了・再起動。HIDを公開し、3種類の購読と接点✓を確認する。必要な場合だけiPad側で手動登録解除・再ペアリング。接点モードをオフへ戻す場合も再起動する。
4. iPadのSafari／写真／ホームで2本指の縦横スクロール、ピンチ、3／4本指のアプリ切り替えを試す。iPadOS設定とアプリ対応に従う結果を記録する。慣性・初動の跳び・指の追加／離脱・1本指への移行・外付けマウス併用・スリープ復帰も確認する。
5. タップ／長押しはWindowsの生接点列がない制約があるため、Magic Trackpadとの同等性を合格条件にしない。失敗時は診断のNativeContactApi／NativeContactFrames／MaximumNativeContacts／MaximumValidNativeContacts、購読・通知容量・OSバージョンのみ採取する。入力内容・座標・HIDペイロードは記録しない。

## 過去版の項目

0.3.4の追加確認: 同じマウス・iPad設定・感度で、ゆっくりした浅い／急な斜め移動と45度移動、全方向、円、方向反転、停止直後を比較します。0.02／0.10／1.00で細かな移動と大きな移動を試し、移動を止めた後に勝手に動かないこと、ドラッグ開始／解除やキー操作との順序が保たれることを確認します。Raw Input有効／互換入力の両方、接続負荷時、Windows復帰と再切り替えも確認します。診断のPreciseMotionTiming・MouseReportIntervalMs・CoalescedMotionを確認しますが、これらの値だけでiPad上の無線遅延や操作感が測れたとは扱いません。

0.3.3の追加確認: iPadへ切り替え→半角／全角で日英切り替え→Ctrl+Alt+QでWindowsへ復帰→キーを離して再びiPadへ切り替え、を複数回試します。キー押下中のスリープ／デスクトップ変更も試し、戻った後にキー解放で再切り替えできることを確認します。本当に文字キー・修飾キー・マウスを押したままなら切り替えを拒否し、未対応キーの押下も消さないことを確認します。拒否が再発した場合は「入力解放診断」の件数・マウス状態・OS物理入力の有無を確認し、キー名や文字が診断へ含まれないことを確認します。

0.3.2の追加確認: iPad操作中にキー・マウスボタンを離してスリープし、Windows操作へ戻ることを確認します。ロック解除→両購読復帰→ショートカット／ボタンで再切り替えを3回繰り返し、アプリ再起動なしで新しい入力を送れること、接続だけで自動再捕捉されないこと、古いキー／クリック／スクロールが再送されないことを確認します。キー押下中のスリープ、Bluetooth切断→再接続も確認します。別端末へ入力が漏れないことを確認します。

日本語キーボードで半角／全角を押し、日本語↔英語の切り替えと英字入力、記号が入らないこと、長押しで1回だけ切り替わること、Alt併用後に修飾キーが残らないことを確認します。iPadへ日本語・英語キーボードを追加した状態で行います。USキーボードのバッククォート、Windows操作中の日本語入力も確認します。

0.3.1の追加確認: ジェスチャー取得をオンにし、「2本指スクロール感度」3.00で短い移動・ゆっくりした移動・指を離す直前・正負方向・横スクロールを確認します。0.25／1.00／3.00／6.00／12.00で比較し、数値入力・推奨値復元・再起動後の保存を確認します。マウスホイール感度の変更で2本指の感度が変わらないこと、Windows復帰後に小数移動や旧ジェスチャーの座標が次回へ漏れないことを確認します。exe・タイトルバー・タスクバー・トレイ・サイドバーのアイコンも確認します。

0.3.0の言語確認: 右上から日本語→English→简体中文へ切り替え、全画面・ジェスチャー選択肢・ショートカット編集・トレイが即時更新されることを確認します。変更時はWindows操作へ戻り、再起動後も選択が保持されることを確認します。Windows由来の例外・過去ログの言語は変換しません。3言語READMEとReleaseのダウンロードリンクも確認します。

0.1.1でユーザーからiPadのマウス操作・キーボード入力成功の報告があります。以下の個別項目、0.1.2の相対入力の精度比較、0.2.0の物理トラックパッド操作は未完了です。まず自動切り替えをオフ、推定復帰もオフにして確認します。

## 0.2.0のジェスチャーとショートカット

対応するWindows Precision Touchpadと実iPadを使用します。標準HIDのスクロール・キー操作への変換を確認する手順であり、iPadネイティブの接点転送の検証ではありません。

1. 更新後にマウスが動かない場合は再接続します。改善しなければ、人がiPadのBluetooth設定でPCの登録を解除し再ペアリングします。0.2.0のマウスレポートは横スクロール追加により7バイトです。
2. 入力設定でジェスチャー取得をオンにし、状態が対応と表示されることを確認します。非対応環境では理由を表示してWindows操作を保つことを確認します。
3. iPadへ切り替えると小さな受け取り画面が前面になること、2本指の縦・横移動がiPadのスクロールに変わること、Windows側のページが動かないことを確認します。
4. 3～5本指の左右・上下スワイプとタップを確認します。Windowsのタスクビュー・デスクトップ切り替え等が起動せず、設定したiPadのアプリ切り替え・検索等が動くことを記録します。割り当て変更と保存も確認します。ホームの⌘Hや拡大縮小キーはiPadOS・アプリの対応に依存します。
5. 対応アプリでピンチを確認します。⌘+／⌘−の離散的なキー操作への変換であり、ネイティブの連続ピンチとは操作感が異なります。
6. Windowsの別画面へフォーカスを移すとWindows操作に戻ること、受け取り画面を閉じても戻ること、復帰ショートカットとEscを3回でも戻ることを確認します。
7. 「入力設定 → ショートカット」で修飾キーとキーを変更し、適用後すぐ新しい組み合わせが動くこと、再起動後も保存されることを確認します。同じ組み合わせの重複は拒否され、他アプリとの競合時に元の設定・登録が残ることを確認します。Escを3回の緊急復帰は変更できません。
8. 取得をオフにすると通常のマウス・キーボード経路へ戻ることを確認します。この設定ではWindowsのシステムジェスチャーを抑制しません。

## 基本入力と復帰

0.1.2の追加確認: 同じ感度で小さい対象のクリック、ゆっくりした斜め移動・細かい往復・長い移動・ドラッグを相対入力と互換入力で比較する。低感度0.02/0.05/0.10での動きを確認する。端末選択後、Ctrl+Alt+Iを押してキーを離すとiPadへ移り、Ctrl+Alt+Qで戻ること、iPadモード中にCtrl+Alt+Iを再押下してもIが入力されないことを確認する。入力方式変更時はWindowsへ戻ることを確認する。

1. WindowsとiPadのBluetoothを有効にし、HID公開を開始。iPadからPC名を選び、両側のペアリング確認に応答する。
2. 一覧に対象端末が現れ、ペア済・キーボード購読・マウス購読が揃うことを確認。揃わない状態では切り替えできないことを確認する。
3. iPadのメモに英数字・Shift・Backspace・Enter・矢印・保持によるリピートを入力する。Windows側に入力が漏れないことを確認する。
4. iPadのハードウェアキーボード配列を合わせ、円・ろ・変換・無変換・かな、日本語変換、左右修飾キー、テンキーを確認する。
5. ポインター移動、左右・中央クリック、短いクリック、ドラッグ、正負のホイール、高分解能ホイールを確認する。
6. Ctrl+Alt+Q、およびEscの別々の3回押下でWindowsへ復帰。復帰キーの解放が漏れず、通常のクリック・入力が続くことを確認する。
7. Shiftやマウスを押したまま切断し、Windowsへ戻ることを確認。再接続時は入力が自動でiPadへ向かわないことを確認する。
8. iPadのBluetoothオフ、圏外、画面ロック、WindowsのBluetoothオフ、スリープ／復帰、アプリの公開停止→再公開、アプリ再起動を確認。必要な再接続／再ペアリング手順を記録する。
9. 自動切り替えをオンにし、右端を押し続けて切り替える。通常の端付近操作、隣接Windowsモニターのある境界、キー・ボタン押下中では切り替わらないことを確認する。
10. 負の原点、100/150/200%混合DPI、モニターの抜き差し、左／上／下の配置を確認する。
11. タスクトレイへの格納・復元・終了、希望する場合のみ自動起動を有効にして再サインイン後のWindows操作モード開始を確認する。
12. 最後に、iPad側でキーを押した状態のプロセス強制終了を確認する。Windows入力の復帰とiPad側の残留入力を別々に記録する。

記録する情報: Windows/iPadOSバージョン、Bluetoothアダプター／ドライバー、購読状態、成功したキー・操作、復帰時間、再接続手順。キー入力内容・パスワードなどは診断へ含めません。
