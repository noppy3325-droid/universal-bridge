# Universal Bridge 0.3.0 — Preview

## English

- Japanese, English, and Simplified Chinese UI, selectable at the top right. Changes apply immediately and persist.
- Translated pages, status/error messages, gesture assignments, shortcut editor, and tray menu. 247 offline messages; no translation service or runtime network access.
- Multilingual README, MIT license/attribution, source archive, checksums, and GitHub build/release workflows.
- Includes relative mouse precision controls, configurable input shortcuts, and trackpad-to-scroll/keyboard mappings from 0.2.0.
- 107 unit tests passed locally; multilingual GUI checks cover all pages and both themes. Actual iPad gesture acceptance remains open.

Download the `win-x64.zip`, extract, and run `UniversalControl.exe`. Requires Windows 11 x64 and BLE Peripheral support. Touchpad capture needs compatible experimental APIs on 24H2 or later. Standard HID mappings do not transmit native iPad multitouch. Unsigned preview binary; no installer.
