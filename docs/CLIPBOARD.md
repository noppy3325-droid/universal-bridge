# Safariでクリップボードを共有

[English](CLIPBOARD.en.md) · 日本語 · [简体中文](CLIPBOARD.zh-CN.md)

v1.06以降では、同じWi-FiにいるWindowsとiPadでテキストを双方向に受け渡せます。iPad専用アプリやインターネットは不要です。共有画面のボタンを使う方式です。テキストのみ、UTF-8で64 KiBまで。画像・ファイル・自動同期には対応していません。

## 初回だけ行う設定

1. PCとiPadを同じWi-Fiにつなぎます。Windowsアプリの「クリップボード共有」でWi-FiのIPアドレスを選び、「共有を開始」を押します。
2. Windowsのネットワーク確認が出た場合は、信頼するプライベートネットワークだけで受信を許可します。ファイアウォールを無効にしたり、ルーターでポートを公開したりする必要はありません。
3. iPadのSafariで、アプリに表示された「初回設定URL」（`http://…:43182/`）を開きます。このHTTP画面は公開証明書と設定案内だけを提供し、クリップボードや接続コードを受け付けません。
4. 証明書の名前とSHA-256を**Windowsアプリの表示と照合**してから、公開証明書をダウンロードします。iPadの「設定 → 一般 → VPNとデバイス管理」でインストールし、「一般 → 情報 → 証明書信頼設定」でその証明書を信頼します。管理対象のiPadでは管理者による許可が必要な場合があります。[Appleの手順](https://support.apple.com/ja-jp/102390)。
5. Safariで「共有画面URL」（`https://…:43183/`）を開きます。証明書の警告が残る場合は先へ進まず、証明書名・信頼設定・URLを確認してください。Windowsアプリの6桁コードを入力すると接続できます。

証明書の秘密鍵はWindowsアカウントで暗号化してPC内に保存します。iPadに渡すのは公開証明書だけです。PCを共有の接続先として信頼する設定なので、名前と指紋を照合してください。利用をやめる場合はiPadの設定から追加した証明書を削除できます。

## テキストを渡す

- **Windows → iPad：** Windowsの任意のアプリでテキストをコピー。iPadのSafariで「Windowsから取得」→「iPadへコピー」を押し、メモ等のアプリに貼り付けます。
- **iPad → Windows：** iPadでテキストをコピー。Safariの共有画面の入力欄に長押し等で貼り付け、「Windowsへ送信」を押します。Windowsの任意のアプリへ貼り付けられます。空欄を送信するとWindowsのクリップボードを消去します。

Safariのコピー許可が得られない場合は、取得したテキストを長押しで選択・コピーしてください。コピーは利用者の操作時に行うSafariの仕様に従います。[WebKitの説明](https://webkit.org/blog/10855/async-clipboard-api/)。

## 接続の管理

- 接続コードは5分間・1回だけ有効です。5回失敗した場合はPCで「新しい接続コード」を押してください。この操作で既存の接続も取り消します。
- 共有は毎回オフで起動します。停止、アプリ終了、Windowsのセッション変更・スリープで接続を失効させます。再開時は新しいコードで接続します。SafariでURLをブックマークできます。
- 内容はHTTPSで転送し、監視・自動同期・履歴保存は行いません。コード、Cookie、共有内容をアプリのログへ書きません。通常のOSクリップボードやブラウザーで利用者がコピーした内容の扱いは各OS／ブラウザーに従います。
- 接続できない場合は、同じWi-Fi、選択IP、Windowsの受信許可、企業・ゲストWi-Fiの端末間通信制限を確認してください。IPが変わった場合は共有を停止し、一覧を更新して開始し直します。PCの公開CAが同じなら証明書の再インストールは不要です。

PC内のTLS通信・認証・失効・文字の往復とブラウザーUIは検証しています。iPad実機のSafari、証明書設定、操作感の最終確認は未実施です。
